# SwiftRoute-Logistics-Dashboard
📌 Project Objective

The objective of this project is to design an interactive Power BI dashboard that enables stakeholders to:

* Monitor operational efficiency

* Track delivery performance

* Identify bottlenecks in hubs and drivers

* Analyze vehicle reliability

* Improve customer satisfaction using data-driven insights

This dashboard supports strategic decision-making in logistics management.

🧰 Tools & Technologies Used

🔹 Power BI Desktop

🔹 Excel / CSV

🔹 DAX (Data Analysis Expressions)

🔹 Data Modeling

🔹 Power Query (Data Cleaning & Transformation)



📊 Business KPIs Covered

📦 Orders

* Total Orders

* Previous Month Orders

* Month-over-Month (MoM) Growth %

🚚 Delivery Performance

* On-Time Delivery %

* Average Delivery Time (Hours)

* Delivery Time MoM Change

😊 Customer Metrics

* Customer Satisfaction (CSAT %)

* CSAT MoM Change
🏢 Hub Operations

* Hub Capacity vs Orders

* Hub Performance Ranking

* Hub Processing Time

👨‍✈️ Driver Performance

* Driver Rating vs Experience

* Drivers with Most Delays

* Monthly Order Trend

* Driver Profile Summary

🚛 Vehicle Analytics

* Operational Readiness

* Vehicle Utilization

* Breakdown Analysis

* Vehicle Age vs Failures

* Model-wise Reliability

🧹 Data Cleaning & Transformation
Steps Performed:

* Removed duplicate records

* Standardized date formats

* Created a Date Dimension table

* Handled missing/null values

* Built relationships between fact and dimension tables

Calculated Metrics:

-- Delivery Duration (Hours)

-- Month-over-Month Growth %

-- Vehicle Age

-- Delay Count per Driver

-- On-Time Delivery %

-- Utilization Metrics



📈 Data Modeling Approach

** Star schema design

** Central Orders fact table

** Connected dimensions: Drivers, Hubs, Vehicles, Date

** Optimized relationships for performance

** Used DAX for advanced time intelligence calculations


🎯 Business Impact

This dashboard enables:

-- Performance monitoring at operational & strategic levels

-- Identification of high-delay drivers

-- Hub overload detection

-- Fleet reliability analysis

-- Improvement in on-time delivery rates

-- Better maintenance and capacity planning
